Classification is the task of assigning discrete labels to input data. Unlike regression, which predicts continuous values, classification algorithms learn decision boundaries that separate data into distinct categories.

This chapter explores Naive Bayes, k-Nearest Neighbors, Support Vector Machines, decision trees, random forests, and ensemble methods such as boosting and bagging.
